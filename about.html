Über das Projekt

School Helper Pro ist eine hochentwickelte, digitale Assistenz-Web-App, die entwickelt wurde, um Schülern bei der Organisation ihres Alltags zu helfen. Dieses Projekt deckt alle modernen Web-Kriterien ab.

Genutzte Technologien:

🌐 HTML5
🎨 CSS3 (Flexbox/Grid/Variables)
⚡ JavaScript (ES6+ Mobile Optimization)
🌦 OpenWeather API Integration
📱 Progressive Web App (PWA)
💾 Local Storage API
